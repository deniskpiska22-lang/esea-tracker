# Локальная тестовая копия

Эта папка является отдельной копией сайта. Изменения не попадут на основной сайт, пока вы вручную не перенесёте их в основной репозиторий и не выполните деплой.

## Запуск интерфейса

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Страница контроля импорта:

```text
/data-status
```

## Обновление данных сезона

```bash
npm run v2:discover-entities
npm run v2:sync
```

Сайт читает `src/data/teams.generated.js` через единый файл `src/data/teams.js`. После синхронизации Vite автоматически перезагрузит страницу.

## Полная цепочка

```bash
npm run sync:full
```

Команды, которые пишут в Supabase, запускайте только с тестовым `.env.local`. Не копируйте production-ключи в тестовую копию, если не хотите менять основную базу.

## Возврат к старому списку

Старый ручной файл сохранён как:

```text
src/data/teams.legacy.js
```
